智能挖机代码管理上手指南

我是谁？→ 点进对应角色，5–10 分钟即可上手日常操作

通用入门

先拿账号、再登录，然后按角色点下方对应卡片上手日常操作。

1

取得账号

账号由平台组（管理员）统一开通，平台已关闭自助注册。开好的账号信息通过邮箱送达——查收工作邮箱即可拿到登录用户名与初始密码。

2

登录

浏览器打开 GitLab 地址，用收到的账号登录，首登后立即改密。

术语速查

英文中文白话
Merge Request (MR)合并请求"请把我分支上的改动合进 main" 的申请，别人评审通过才算数
CI / Pipeline持续集成 / 流水线服务器替你自动编译+测试；push 后自动跑，红了必须修
Protected branch (main)保护分支只能通过 MR 合入，谁都不能直接 push 的主干
tag / Release标签 / 发布给某个 commit 贴版本号（tag）；Release 是带附件的正式发布页
manifest.json清单文件藏在制品里的"身份证"：哪个 commit、何时、哪台机器构建
ci-templatesCI 模板仓库全项目共用的 CI 模板仓库，规则改一处、全部仓库生效
Harbor—容器镜像仓库：CI 构建的镜像归宿在这里，构建区拉 base 镜像也走它的代理
MinIO—对象存储：数据集、模型权重等大文件归宿，git 里只存清单与指针
field-dropzone投放区现场数据 write-only 投放桶：只能往里投，不能删/列别人的
DLP (Data Loss Prevention)数据防泄漏集团防泄漏系统：终端透明加解密——文件在硬盘上自动加密，拷出去打不开
intake受理台所有需求 / 缺陷的唯一进料口仓库：按模板建单，3 日内分诊
triage分诊域 Owner 把单移交 / 打回 / 婉拒，并代打来源与状态标签
scoped labels (Status:: / Source::)作用域标签形如"状态::待受理"的全组统一标签——看板列就来自它
Milestone里程碑版本节点（如"固件 v2.3·2026Q4"），进度按单数百分比看
Closes #issue关单指令写在 MR 描述里的关单指令：代码合入那一刻，单自动关闭
