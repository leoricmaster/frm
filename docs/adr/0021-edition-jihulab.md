# ADR-0021：版本策略——极狐 GitLab 免费版运行（取代 ADR-0002）

- 状态：已接受
- 决策日期：2026-09-09
- 来源：ADR-0002 重开（新增考量驱动，非原重开条件触发）
- 关联：ADR-0001（平台选型不变，仅发行版变更）

## 背景

ADR-0002 选定"安装 `gitlab-ee` 包不注入 license，按免费功能运行"。2026-09-09 变更为极狐 GitLab：驱动是**国产化/信创合规预期与本地支持**（信创要求尚待集团确认，但免费版零成本，切换不必等确认）。原 ADR-0002 的两条重开条件（审批硬约束、审计事件流对接）均未触发，本次属新增考量下的方向修正，留痕于此。

## 决策

1. 发行版采用**极狐 GitLab**（GitLab 官方中国发行版，镜像 `registry.gitlab.cn/omnibus/gitlab-jh`），**免费版档位运行、不注入 license**：免费版无需申请 license、私有化部署无用户数限制，功能与上游免费档（CE）等价；
2. 功能替代与升级路径沿用 ADR-0002：缺失的专业版功能（审批规则/推送规则/审计事件流/分组同步）以制度与 CI 替代，痛点成真或集团审计提出要求时购买专业版 license 注入升级，无需重装；
3. 既有文档中的"CE"能力边界表述一律读作"免费版"（功能等价），不回改历史 ADR 正文。

## 考量

- 切换零新增成本：免费版运行方式与原"ee 免 license"完全相同；
- 极狐收益：国内镜像源稳定（原方案 ee 命名空间曾被镜像源限流）、原生中文界面降低推广摩擦、官方本地支持与国产化合规叙事；
- 同源同版本号（原型由 CE 19.3.1 换装 19.3.1-jh.0），仓库结构、CI 配置、权限模型零改动，既有验证结论跨发行版成立。

## 否决的备选方案

- 维持 gitlab-ee 免 license（ADR-0002 原案）——放弃国产化合规与本地支持，且镜像源曾被限流；
- 极狐专业版 license 起步——为尚不存在的痛点付费（同 ADR-0002 的否决理由）。

## 后果

- 正面：合规叙事与中文界面；升级路径无损（license 注入即生效）；
- 代价：免费档能力边界不变（审批、推送拦截仍是制度约束）；版本节奏跟随极狐发布；
- 行动项：联系极狐确认免费档支持渠道与升级报价。

## 重新打开的条件

- 集团明确只认全球版 GitLab、不认极狐 → 回退 ADR-0002 路线；
- 极狐免费版政策变化（新增 license 要求或用户数限制）→ 重议发行版与档位。
